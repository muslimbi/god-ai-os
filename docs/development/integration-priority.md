# Integration Priority Matrix

## P0 — Required for MVP

- Linux/Bash
- Python
- Git
- Docker
- REST
- SSH
- PostgreSQL/SQLite
- Redis
- OpenAI-compatible model API
- Ollama
- MCP

## P1 — Required for autonomous developer/operations workflows

- GitHub
- GitHub Actions
- Playwright
- HyperAgent
- Kubernetes
- Terraform
- Ansible
- Prometheus
- Grafana
- OpenTelemetry
- Vault/secret manager

## P2 — Network and enterprise expansion

- MikroTik RouterOS
- Cisco IOS/IOS-XE
- SNMP
- Nmap for authorized diagnostics
- WireGuard
- FRRouting
- ERPNext
- Odoo
- Zoho CRM
- WHMCS
- WooCommerce
- Grandstream UCM
- Asterisk/FreePBX
- Vicidial

## P3 — Broad ecosystem

- AWS
- Azure
- Google Cloud
- DigitalOcean
- Vultr
- Cloudflare
- GitLab
- Slack
- Teams
- Telegram
- WhatsApp Business
- additional databases and SaaS platforms

## Selection Rule

Do not implement every connector in the core. Implement a stable adapter SDK and add connectors incrementally based on real missions and community demand.
