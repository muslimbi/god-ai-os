# Execution Lifecycle

```text
REQUEST
  ↓
INTENT
  ↓
PLAN
  ↓
CAPABILITY DISCOVERY
  ↓
RISK EVALUATION
  ↓
AUTHORIZATION
  ↓
EXECUTION
  ↓
OBSERVATION
  ↓
VERIFICATION
  ↓
RECOVERY (if required)
  ↓
REPORT
```

## Rule

A tool returning `success` is not sufficient.

The expected state must be independently verified whenever practical.
