# Architecture Overview

GOD AI OS is organized as a layered system.

```text
User Interfaces
      ↓
GOD Control Plane
      ↓
AIOS / Agent Runtime
      ↓
Host OS
      ↓
Infrastructure
```

The control plane is split into:

- Intelligence
- Execution
- Governance
- State & Memory
- Observability

See [`ARCHITECTURE.md`](../../ARCHITECTURE.md) for the complete design.
